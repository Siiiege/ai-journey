## 三个目标岗位

1. **火山引擎 · AI Agent 应用开发/架构师（北京）**——Agent 整体架构（大模型适配、记忆库、知识库、Skills）、任务规划与决策执行、性能与稳定性。
2. **火山引擎 · 企业 Agent 应用开发（多城市）**——Agent 观测（链路追踪、指标、日志）与**评测框架**；JD 原文要求会 Cursor/Codex/Claude Code 提效。
3. **美团 · AI 全栈工程师（多城市）**——AI 产品前端界面 + 后端服务全栈。**与「前端出身 + 补模型层」最对口的岗位类型，是 Phase 2 作品的直接对标。**
