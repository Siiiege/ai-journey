# 目标岗位 JD 分析（北极星）

> 抓取于 2026-10-13，字节社招官网 + 美团社招官网原文。每季度重读一次，校准学习重点。

## JD ①：AI Agent应用开发工程师/架构师 - 火山引擎（北京）

**职责**：Agent 整体架构（大模型适配、记忆库、知识库、Skills）；任务规划/逻辑推理/决策执行；性能优化与稳定性（延迟、并发、容灾）；沉淀通用 Agent 框架与组件库。

**要求原文**：
1. 本科及以上，计算机/软工/AI/数学相关专业
2. 2 年以上后端开发或 AI 应用开发经验，有 Agent 项目经验优先
3. 熟悉大语言模型基本原理、**能力边界**与应用场景
4. Python / Go / **Node.js** 至少一门

## JD ②：企业Agent应用开发工程师 - 火山引擎（上海/北京/杭州/深圳）

**职责**：Agent 观测（链路追踪、指标监控、日志分析）与**评测框架**；公有云 Agent 项目全链路交付。

**要求原文**：
1. 本科及以上
2. 有 LLM 应用开发经验（**RAG、Agent、Workflow**）
3. "熟练使用 Cursor、Codex、Claude Code 等 AI 编程工具提升开发效率"（原文）
4. Java/Go/Python + 分布式中间件
5. 关注 **LLM、Agent、MCP、Harness** 前沿

## JD ③：AI全栈工程师 - 美团（北京/上海/成都/深圳）

**职责原文（列表页）**："参与 AI 应用的全栈开发：负责 AI 产品功能的前端界面（Web/小程序）与后端服务的设计与实现，保障高可用与用户体验"。

**定位意义**：与"前端出身 + 补模型层"量身定制的岗位类型，是作品 2 的直接对标。
